> 范围：`apps/web` 控制面（总览 / 收件箱 / 任务 / 项目 / 供应商 / Agent / 路由图 / 编队 / 自动化 / 网关观测 / 通知 / 平台状态 / 设置）。
> 方法：Impeccable 结构化审查 → UI UX Pro Max 定令牌 → Emil Kowalski 微交互/极端数据 → Vercel 工程与无障碍核对。
> 证据：改版前 `.cache/ui-overview.png` 等（19:19 截图）；改版后 `.cache/ui-v3-*.png`。

## 结论摘要
当前页面功能完整、结构清楚，但存在“模板味与不一致”：多处 `:root` 覆盖导致色调/圆角/阴影漂移，标题重复，总览留白过大，移动端导航坍缩成整屏竖排，装饰性渐变偏多，无障碍基础（`aria-current`、skip-link、焦点环）缺失。v3 全部收敛为单一令牌体系。

## 问题清单（按严重度）
| id | 位置 | 现象 | 严重度 | 修复 |
| --- | --- | --- | --- | --- |
| A1 | styles.css | `:root` 被重复定义 5 次，暖色/冷色/不同圆角混用，最终态不确定 | P0 | 新增权威 v3 令牌层，统一冷中性画布 + 单一主色 + 固定半径/阴影 |
| A2 | 顶部栏 + 各页 `page-head` | 顶部 `h1` 与页面 `h2` 同为页面名，重复两级标题 | P1 | 顶部改面包屑「大铭 / 页面」，页面 `h2` 为唯一大标题 |
| A3 | 总览 | KPI 下方 `overview-cols` 只到半屏，下半页大片空白 | P1 | 增加 8 宫格「快捷入口」，KPI 与卡片间距放大，填满首屏节奏 |
| A4 | 移动端 (≤1080/720) | `rail` 坍缩后按钮 `width:100%` 逐行堆叠成整屏竖排菜单 | P1 | rail 改为单行横向可滚动命令条；仅显 logo + 图标标签，设置/帮助并入条尾 |
| A5 | 全局 | 缺 `aria-current`、无 skip-link、焦点环不统一 | P1 | 导航加 `aria-current="page"`；全局 `:focus-visible` 2px 主色环；加 skip-link |
| A6 | KPI/标题/背景 | 渐变文字 + KPI 径向光斑 + aurora 光斑叠加，“AI 味”过重 | P2 | 关闭 aurora/径向光斑/渐变标题；一屏一个视觉焦点，KPI 强调仅用淡底+左边线 |
| A7 | 卡片 | 圆角 13/14/16、阴影多套、内距不一 | P2 | 统一 `--radius:14px` + 软阴影，卡片内距 16–18px |
| A8 | 按钮 | primary/ghost/指令按钮样式各自为政，禁用态过淡 | P2 | 统一按钮配方与禁用态对比，按压 `scale(.975)` |
| A9 | 数据 | 长模型名/长标题/大金额/大 token 未统一截断与等宽 | P2 | `min-width:0`+省略号；数字 `tabular-nums` |
| A10 | 空态 | 收件箱空卡片过大且缺“下一步” | P2 | 空态 = 插画 + 一句话；快捷入口承接下一步 |

## 反 AI 味与克制
- 关闭多色光斑与渐变标题，保留极轻 rail 噪点（0.12）。
- 主色 `#4f46e5` 仅用于主按钮 / 激活态 / 关键数字 / 链接。
- 空态、加载、错误三类状态齐全；颜色 + 文案双编码。
