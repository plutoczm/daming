# UI/UX Pro Max（项目加工版）

> 来源与致谢：社区高星技能 `ui-ux-pro-max-skill`（设计知识库检索思路）与 [garden-skills](https://cloud.tencent.cn/developer/article/2676247)（6.2k★，25 种风格配方）。本文件只保留可执行规则，不复制其原始内容。

## 使用顺序
1. 先在 `daming-ui-design` 的令牌范围内选风格。
2. 再按本文件选择页面骨架、密度、字体与交互节奏。
3. 最后按验收清单检查可访问性与响应式。

## 风格配方（大铭可用）
- **Control-plane / Linear**：深色 rail + 浅色工作区；高对比标题、低对比辅助文字；卡片 16px 圆角；列表行 44–56px。
- **Magpie desktop**：暖灰画布 `#f6f5f2`；白色卡片 + 1px 细边；头像色块；状态点；等宽数字。
- **HiFox collaboration**：收件箱一条任务一行；状态 pill；右侧详情抽屉；空态插画。
- **DSH session**：侧栏分组；沉浸式内容区；工具/代码块独立卡；语义 token。

## 版式与间距
- 页面最大宽度 1180–1560px；主内容左右至少 24px。
- 间距阶梯：4 / 8 / 12 / 16 / 24 / 32 / 48。
- 标题：22px/600；卡片标题 13–14px/650；正文 12–13px；辅助 10.5–11.5px。
- 行高：正文 1.55–1.7；标题 1.2–1.3。

## 色彩与对比
- 主色只用于：主按钮、激活态、关键数字、链接；不要整页铺主色。
- 成功/警告/失败使用 soft 背景 + 深色文字；颜色必须配文案或形状。
- 正文对比度 ≥ 4.5:1；大标题 ≥ 3:1。

## 交互与反馈
- 每个写操作要有 loading → 成功/失败 Toast。
- 危险操作二次确认；未知结果明确说“结果未确认”。
- 列表 hover 抬升 ≤2px；按压 scale ≥ .985。
- 所有动效支持 `prefers-reduced-motion`。

## 验收清单
1. 页面按“一个导航项 = 一个独立页面”，不是长滚动拼贴。
2. 空态、加载态、错误态都有。
3. 移动端 900px 以下单列可用。
4. 不出现“离线演示 / fixture”作为主路径。
